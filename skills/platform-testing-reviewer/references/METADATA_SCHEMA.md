# Test Metadata Schema

This document provides the JSON Schema for test metadata sidecars required by Platform Testing Standard §11.

## JSON Schema

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$id": "https://platform.shinobi.internal/schemas/test-metadata/v1.0.0",
  "title": "Platform Testing Standard - Test Metadata",
  "description": "Required metadata for all tests per PTS-1.0 §11",
  "type": "object",
  "additionalProperties": false,
  "required": [
    "id",
    "level",
    "capability",
    "oracle",
    "invariants",
    "fixtures",
    "inputs",
    "risks",
    "dependencies",
    "evidence",
    "compliance_refs",
    "ai_generated",
    "human_reviewed_by"
  ],
  "properties": {
    "id": {
      "type": "string",
      "pattern": "^TP-[a-z0-9-]+-[a-z0-9-]+-\\d{3}$",
      "description": "Test ID in format TP-<service>-<feature>-NNN (zero-padded 3 digits)",
      "examples": ["TP-ecs-fargate-service-synthesis-001", "TP-lambda-api-binding-042"]
    },
    "level": {
      "type": "string",
      "enum": ["unit", "integration", "e2e"],
      "description": "Test level: unit (isolated), integration (real boundaries), e2e (external observable)"
    },
    "capability": {
      "type": "string",
      "description": "Short behavior description of what this test validates",
      "minLength": 1,
      "examples": ["ECS Fargate Service synthesis with default configuration", "Lambda API binding to S3 bucket"]
    },
    "oracle": {
      "type": "string",
      "enum": ["exact", "snapshot", "property", "contract", "metamorphic", "trace"],
      "description": "Primary oracle type for this test"
    },
    "invariants": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "Properties that must always hold (may be empty array)",
      "examples": [["Service created", "Task definition configured", "Tags applied"], []]
    },
    "fixtures": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "Fixture names used in this test (may be empty array)",
      "examples": [["TestFixtureFactory", "MockVpc"], ["InMemoryDatabase"]]
    },
    "inputs": {
      "type": "object",
      "required": ["shape"],
      "properties": {
        "shape": {
          "type": "string",
          "description": "Domain summary of input structure",
          "examples": ["ComponentSpec with minimal config", "Binding directive with S3 capability"]
        },
        "notes": {
          "type": "string",
          "description": "Additional notes about inputs, including mask_rules for snapshot tests",
          "default": ""
        }
      },
      "description": "Input structure and notes"
    },
    "risks": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "Identified risks (may be empty array)",
      "examples": [[], ["Network dependency", "External service call"]]
    },
    "dependencies": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "Dependencies (packages, services, etc.)",
      "examples": [["aws-cdk-lib", "@shinobi/core"], ["vitest", "aws-cdk-lib/assertions"]]
    },
    "evidence": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "Evidence URIs (logs, junit, artifacts) - required for integration/E2E tests",
      "examples": [[], ["logs/test-run-2025-01-15.log", "junit/test-results.xml"]]
    },
    "compliance_refs": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "References to compliance standards validated by this test",
      "examples": [
        ["std://platform-component-api-spec", "std://platform-tagging-standard"],
        ["std://platform-logging-standard"]
      ]
    },
    "ai_generated": {
      "type": "boolean",
      "description": "Whether this test was generated by AI"
    },
    "human_reviewed_by": {
      "type": "string",
      "description": "Human reviewer name or group (required if ai_generated=true, may be empty if false)",
      "examples": ["platform-team", "john.doe", ""]
    },
    "mask_rules": {
      "type": "array",
      "items": {
        "type": "string"
      },
      "description": "Mask rules for snapshot tests (required if oracle=snapshot)",
      "examples": [["timestamp", "uuid", "arn"], ["hash", "id"]]
    }
  },
  "if": {
    "properties": {
      "oracle": { "const": "snapshot" }
    }
  },
  "then": {
    "required": ["mask_rules"]
  },
  "if": {
    "properties": {
      "ai_generated": { "const": true }
    }
  },
  "then": {
    "properties": {
      "human_reviewed_by": {
        "type": "string",
        "minLength": 1
      }
    },
    "required": ["human_reviewed_by"]
  }
}
```

## Example Metadata Files

### Unit Test Example

```json
{
  "id": "TP-ecs-fargate-service-synthesis-001",
  "level": "unit",
  "capability": "ECS Fargate Service synthesis with default configuration",
  "oracle": "contract",
  "invariants": ["Service created", "Task definition configured", "Tags applied"],
  "fixtures": ["TestFixtureFactory", "MockVpc"],
  "inputs": {
    "shape": "ComponentSpec with minimal config",
    "notes": "Commercial framework"
  },
  "risks": [],
  "dependencies": ["aws-cdk-lib", "@shinobi/core"],
```

## Validation Rules

1. **ID Format**: Must match `TP-<service>-<feature>-NNN` with zero-padded NNN
2. **Conditional Fields**:
   - If `oracle="snapshot"`, `mask_rules` is required
   - If `ai_generated=true`, `human_reviewed_by` must be non-empty
   - If `level="integration"` or `level="e2e"`, `evidence` should not be empty
3. **Arrays**: All array fields must be present (may be empty `[]`)
4. **Strings**: All string fields must be non-empty (except `human_reviewed_by` when `ai_generated=false`)
